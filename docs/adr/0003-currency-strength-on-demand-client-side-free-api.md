# 通貨強弱はボタン押下でクライアントから無料キー不要API（Frankfurter/ECB）を叩き、日次で算出・表示する

## Status

superseded by ADR-0004

> 「サーバーなし・キー不要・日次」で一旦実装したが、「1時間ごとに更新（値が毎時動くイントラデイ）」の
> 要望により撤回。イントラデイはキー必須のため、GAS以外のサーバー（Cloudflare Workers）で再構成する。
> 現行方針は [ADR-0004](./0004-currency-strength-intraday-on-cloudflare-workers.md) を参照。

## Context / Decision

ADR-0002 では「毎時」表示のためサーバー（GAS）で Twelve Data の時系列を取得・キャッシュしていたが、
**「GAS を使いたくない。ボタンを押したら無料 API から通貨強弱を表示したい」** という要望により方針転換した。

「サーバーなし・キー秘匿・毎時」の3つは同時に成立しない。GAS（サーバー）を外す以上、**毎時（イントラデイ）を諦める**代わりに、サーバーもキーも不要な構成を選ぶ。

- **オンデマンド（ボタン起動）。** 自動の時間トリガーや常駐監視はやめ、ユーザーが「通貨強弱」ボタンを押したときだけ取得・算出・表示する。開いている間だけ動く純クライアント処理。
- **データ源は Frankfurter（ECB由来、無料・APIキー不要・CORS許可）。** ブラウザから直接叩けるため、公開バンドルに秘匿情報を載せる問題が発生しない。`base=JPY` のレートは「1円あたりの外貨額」なので、**逆数を取って円/単位（＝既存アプリと同じ X/JPY の向き）に変換**してから、[ADR-0002] と同じ等加重平均式で8通貨のスコアを算出する（式はテスト済みの `src/lib/strength.ts` を再利用）。
- **窓は「直近2営業日」。** ECB 参照レートは営業日に日次公表されるため、時系列の直近2日（週末・祝日はスキップ）の変化率で判定する。イントラデイ（毎時）は無料キーなし源からは取得できないため、**日次**とする。

## Consequences

- **「毎時」は廃止。** クロックアワー窓・キャッシュ・stale（古い）表示・カバレッジ時間帯（平日15:00〜26:00）といった ADR-0002 由来の概念はすべて不要になった。用語は CONTEXT.md（Strength window / Strength refresh）を更新済み。
- **GAS 実装を撤去。** `gas/currencyStrength.gs` と `VITE_GAS_STRENGTH_URL` は削除。price-move alert（ADR-0001）の GAS はこの変更の影響を受けない。
- **粒度は日次。** 短時間の値動きは反映されない（イントラデイが必要になったら有料キー＋サーバー、すなわち ADR-0002 系の再検討が必要）。
- **失敗時は電卓を妨げない。** 取得失敗・部分欠損時はボタン近傍にエラーを表示するだけで、ロット計算機能はそのまま使える。
- **秘匿情報なし。** API キーを一切持たないため、鍵の管理・ローテーション・露出リスクが消える。
