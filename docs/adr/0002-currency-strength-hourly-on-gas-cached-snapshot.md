# 通貨強弱は GAS 上で毎時スナップショットとして算出・キャッシュし、クライアントは表示のみ行う

## Status

superseded by ADR-0003

> 当初は「毎時」表示のためサーバー（GAS）でTwelve Dataの時系列を取得・キャッシュする設計を採用したが、
> 「GASを使いたくない／ボタン押下で無料APIから表示したい」という要望により撤回。
> 現行方針は [ADR-0003](./0003-currency-strength-on-demand-client-side-free-api.md) を参照。

## Context / Decision

「毎時、通貨強弱を表示」したい、という要望から検討した。通貨強弱（Currency strength）は、アプリが扱う **8通貨** それぞれについて、他7通貨に対する % 変化を等加重平均した相対モメンタム指標である（用語は [CONTEXT.md](../../CONTEXT.md) 参照）。算出には各レートの「今」と「窓開始時」の値、すなわち時系列データが必要になる。

- **時系列データ源は Twelve Data、実行場所は GAS。** 既存のレート源（GOOGLEFINANCE 経由 / ExchangeRate-API）は _display-grade_（遅延・日次）で、時刻をまたぐ変化を出せない。分〜時間単位の時系列が取れる Twelve Data を使うが、そのAPIキーは [ADR-0001](./0001-price-move-alerts-on-gas-rolling-spot.md) の方針どおりクライアント（GitHub Pages 上の公開バンドル）には置かない。よって取得・算出は **priceAlert の GAS プロジェクトを拡張**して実装する（Twelve Data キー・`PropertiesService`・時間トリガーが既に揃っており、キーを二重管理しない）。クライアントは既存の `VITE_GAS_RATES_URL` と同じ JSONP で完成済みスナップショットを受け取り、**表示のみ**行う（強弱の算術は GAS 側の1箇所に集約＝テスト容易）。

- **GAS がスナップショットを算出してキャッシュし、クライアントはキャッシュを読むだけ。** Twelve Data 無料枠は 800 req/日で、price-move alert が平日約660 req/日を消費するため残余は約140 req/日。開くたびにクライアントから時系列を引くと端末数×リロード数で青天井になり枠を食い潰す。GAS の毎時トリガーが7本の X/JPY 時系列を1回だけ取得してスナップショットを `CacheService`/`PropertiesService` に保存し、全クライアントはそれを読む。

- **窓は「直前の確定クロックアワー」。** :00 の再計算時（例 10:00）、窓は 09:00→10:00（直近2本の1時間足の終値）。ローリング（now−60min）ではなくクロック境界に揃えることで、毎時トリガーと一致し、値が1時間安定し、ラベル（「09:00–10:00」）が明確になる。

## Consequences

- **算出時間帯は平日 15:00〜26:00 JST に限定。** 24時間毎時取得だと 24×7=168 req/日で残余140を超え、アラートを枯渇させる。ロンドン↔NY重複（= アラートと同じ窓、11h×7=77 req/日）に限定する。CONTEXT.md の通り重複帯は流動性・ボラティリティが最も高く、強弱の分散が意味を持つ時間帯でもある。
- **窓外・週末は「古い（stale）」スナップショット表示。** 時間外・週末は最後に算出したスナップショットに stale バッジを付けて表示し、再計算はしない。
- **時間足フォールバックは存在しない。** レート計算のような ExchangeRate-API フォールバックは日次のため強弱には使えない。GAS 停止・キャッシュ空（初回デプロイ）・取得失敗時は、キャッシュがあれば stale 表示、無ければ「利用不可」プレースホルダを出す。**電卓本体の動作は強弱の失敗に一切影響されない**。
- **UI は折りたたみ式ランキングバー。** モバイル単一画面を守るため、既定は折りたたみ（ヘッダのみ）。展開で8通貨を強い順に発散色バー＋%で表示。クライアントは最終スナップショットを `localStorage` にキャッシュし、初回描画・オフライン時に stale 付きで即表示する。
- **秘匿情報。** Twelve Data キーは引き続き priceAlert GAS の Script Properties にのみ置き、クライアント用の新規 env var は取得先URL（`VITE_GAS_STRENGTH_URL`）のみとする。
